## Stub API

### Install dependencies:

```bash
npm install
```

### Start the MET-A-003 scenario-state stub: 
```bash 
npm run stub
```

### The stub runs at:
http://localhost:4010

### Endpoints:
GET  /api/v1/scenario-state

GET  /api/v1/scenarios

GET  /api/v1/scenarios/{scenarioId}

GET  /api/v1/metro-lines/{lineId}

POST /api/v1/position-reports
